VidFlow AI Studio

Blueprint Arsitektur & Perencanaan Sistem

Dokumen Rahasia & Strategis | Disiapkan untuk: CEO VidFlow

1. Ringkasan Eksekutif (Executive Summary)

Dokumen ini menguraikan peta jalan (roadmap) teknis untuk mentransformasi VidFlow dari platform Auto-Uploader menjadi Generative AI Content Engine yang setara (1:1) dengan OpusClip.

Tujuan utama pengembangan ini adalah memberikan kemampuan kepada sistem VidFlow untuk menerima satu video durasi panjang (Podcast/Vlog), menganalisisnya menggunakan Large Language Models (LLM), dan secara otomatis memecahnya menjadi belasan klip vertikal berkualitas tinggi (siap viral) lengkap dengan pelacakan wajah dan subtitle dinamis.

2. Arsitektur Teknis 4-Fase (The 4-Phase Pipeline)

1

Injeksi & Transkripsi Audio

  • Pengguna mengunggah URL YouTube atau file MP4 mentah.
  • Sistem menggunakan FFmpeg untuk mengekstrak layer audio (MP3).
  • Sistem memanggil Deepgram API (Nova-2 Model) untuk melakukan Speech-to-Text dengan kecepatan tinggi.
  • Output: Teks transkrip lengkap beserta Word-Level Timestamps (akurasi milidetik untuk setiap kata).
2

Analisis Otak AI (Viral Hooks)

  • Transkrip dikirim ke OpenAI GPT-4o API atau Claude 3.5 Sonnet.
  • LLM diinstruksikan untuk mencari momen paling emosional/menarik (durasi 30-60 detik).
  • LLM menghasilkan metadata: Judul Klip, Deskripsi, Virality Score (1-100), dan Titik Potong Waktu (Start/End).
  • Output: Data JSON berisi 5-10 rekomendasi klip terbaik.
3

Pelacakan Wajah & Pemotongan

  • Karena server VPS (t4g.medium) tidak sanggup merender video AI, tugas ini dilempar ke Shotstack API atau Cloudinary.
  • AI melakukan konversi video rasio lanskap (16:9) menjadi format vertikal TikTok/Reels (9:16).
  • Fitur Auto Face-Tracking memastikan wajah pembicara utama selalu berada tepat di tengah layar.
4

Subtitel Dinamis & Distribusi

  • Memasukkan subtitel tebal gaya "Hormozi" berdasarkan data Word-Level Timestamps dari Tahap 1.
  • Injeksi Emoji otomatis berdasarkan konteks kalimat (via LLM).
  • Output Akhir: Klip video vertikal final yang langsung disambungkan ke sistem Auto-Uploader VidFlow yang sudah ada.

3. Transformasi Model Bisnis & Keuangan (Monetisasi)

Operasional AI memiliki biaya per panggilan API (Transkripsi, LLM, Rendering). Untuk melindungi perusahaan dari kebangkrutan akibat tagihan API yang membengkak, VidFlow dilarang keras menjual paket "Unlimited". Skema harus diubah menjadi Sistem Kredit (Pay-As-You-Go).

Estimasi Modal API (HPP)

Biaya memproses 1 Menit Video:

  • Transkrip (Deepgram): ~$0.004 / menit
  • Otak AI (GPT-4o-mini): ~$0.001 / menit
  • Video Render (Shotstack): ~$0.075 / menit
  • Total Modal: ~$0.08 (Rp 1.280) per Menit

Proyeksi Keuntungan (Per User)

Contoh: Menjual Paket $15 (Rp 240.000)/bulan

  • Harga Jual: Rp 240.000
  • Jatah Diberikan: 100 Menit (100 Kredit)
  • Maksimal Modal (API): Rp 128.000
  • Net Profit Minimum: Rp 112.000 (46%)

Sistem Perlindungan Modal (Credit & Top-Up Logic)

Mekanisme ini memastikan pengeluaran operasional selalu dibayar di muka oleh pelanggan.

  • 🔋
    Pembakaran Kredit (Burn Rate):

    Setiap kali pengguna menekan tombol "Generate to Clip", sistem mengecek durasi video asli. Jika video berdurasi 30 menit, sistem langsung memotong 30 Kredit dari saldo pengguna.

  • 🛑
    Kunci Otomatis (Auto-Lock):

    Jika sisa kredit pengguna (misal: 10 Kredit) lebih kecil dari durasi video yang diunggah (misal: 20 menit), tombol Generate akan terkunci. Hal ini mencegah tagihan API terus berjalan.

  • 💳
    Siklus Top-Up (Pay-As-You-Go):

    Jika kredit habis di pertengahan bulan, pengguna diwajibkan membeli paket Add-on Top-Up (misal: Beli 50 Kredit tambahan seharga $10). Ini menciptakan sumber pendapatan berulang ganda dari satu pengguna yang sama.

4. Peta Jalan Pengembangan (Roadmap)

Bulan 1: Riset API & Prototipe Backend

Mengintegrasikan Deepgram API dan OpenAI. Membuat skrip Python/PHP untuk mengekstrak transkrip dan mendapatkan skor viral.

Bulan 2: Integrasi Video Rendering

Menghubungkan Shotstack API untuk melakukan face-tracking dan auto-crop 9:16. Mendesain template teks subtitle animasi.

Bulan 3: UX/UI & Sistem Kredit

Membangun antarmuka (UI) di Laravel/React untuk memutar hasil klip. Mengintegrasikan sistem pembayaran Stripe dan logika pemotongan saldo (Credits) pada database pengguna.
